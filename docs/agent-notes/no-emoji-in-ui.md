No emoji in anything player-facing: UI texts, popups, notifications, menu titles, FigCraft designs, release notes. Emoji used alone as an icon (side buttons, badges) are tolerated only until drawn icons replace them.

**Why:** the user finds emoji "trop IA" (too AI-looking); they asked twice (release notes, then the whole game after seeing one on a ghost-coin popup).

**How to apply:** write labels as plain words ("+3 Ocean", "Shiny Golden Guppy", "Done"); when an icon is needed, draw one (FigCraft → PNG → upload) instead of using an emoji.
